# Cheer Coach AI

Responzivní webová aplikace v češtině pro osobní plánování cheerleadingového tréninku. Obsahuje knihovnu trenérských karet, seznam videoodkazů, evidenci stunt groups, osnovu sestav, plánovač a export/import JSON záloh.

## Použití

Otevři web v Safari na iPadu. Pro ikonu na ploše klepni na **Sdílet → Přidat na plochu**. Plány, vlastní karty, odkazy, skupiny a sestavy se ukládají pouze lokálně v prohlížeči; automatická synchronizace mezi zařízeními není dostupná.

## Bezpečnost

Karty nenahrazují přímý dohled odpovědného kvalifikovaného trenéra a potřebných spotterů. Legalitu prvku ověř pro konkrétní soutěž, věkovou skupinu a sezonu. Při bolesti, nejistém úchopu, ztrátě rovnováhy, únavě zhoršující techniku nebo nejasném povelu trénink zastav a použij trenérem určenou regresi.

Aplikace neukládá data na server a neobsahuje AI, live video, import videa ani osobní či zdravotní údaje sportovců.

## Vývoj

Jde o statickou aplikaci bez závislostí, backendu a API klíčů. GitHub Actions nasazuje soubory aplikace na GitHub Pages po změně větve main.


## Přehrávání a práce na telefonu

Videa z YouTube, Vimeo, TikToku a Instagramu nebo přímé video soubory lze přehrát přímo v aplikaci, pokud zdroj dovolí vložení. Odkaz můžeš propojit s kartou i konkrétním drilem. Na iPadu se detail otevře vedle levého menu, na telefonu přes celou obrazovku; mobilní navigace je přizpůsobená dotykovému ovládání. Externí obsah aplikace nestahuje; dostupnost přehrávání určuje zdrojová platforma.
